INTRODUCTION

カワイイ女の子が 人の心から「病み」を回収する ワイヤーアクション＆アドベンチャー

目を覚ますと、そこは誰かの「心」の中だった。
自分がなぜここにいるのかも分からない少女「ユメミ」。
元の世界へ帰るため、彼女は人々の深層心理へ潜り、
その心に巣食う「病み菌」を回収していく……

GAME

チョーカーで心の奥へと突き進め！

ユメミを操作して、人の精神世界へダイブ。
不思議なチョーカーを使ったワイヤーアクションで、病み菌の回収を目指そう。

Game 01

チョーカーを使ってワイヤーアクション

ユメミのなが～い不思議なチョーカーを操り、人の精神世界を駆け抜けろ！

壁や天井にチョーカーを引っかけてスイングしたり、ぶら下がったりしながらステージを進んでいこう。

Game 02

カワイイ×ヤミの精神世界を進め！

メルヘンチックだけど、どこか不気味な精神世界――。襲いかかる敵や仕掛けをかいくぐり、世界の奥を目指そう。

世界のどこかにある「記録の欠片」を集めれば、いいことがあるかも……？

Game 03

最深部でのボスとの対決

精神世界の最深部では、強力なボスとの戦いが待っている。激しい戦闘に打ち勝ち、精神世界から病み菌を回収しよう。

CHARACTER

YUMEMI

ユメミ

本作の主人公。
深層心理世界で目覚めた謎の少女。
ここにいる理由も、
自分自身のこともわからない。

元の世界へ帰るため、
不思議なチョーカーを手にして
心理世界を駆け巡る。

RISUKA-CHAN

リスカちゃん

ユメミと行動をともにする、
不思議なぬいぐるみ。
精神世界や病み菌について色々と教えてくれる、
頼れる（？）案内役。

どうしてそんなことを知っているのかは……？
